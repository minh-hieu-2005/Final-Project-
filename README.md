# Your Healthy Schedule

Ứng dụng lập lịch sống lành mạnh (Next.js 15 + Prisma + Clerk + Stripe + OpenAI).

## Bắt đầu từ đâu?
1. Mở thư mục này bằng VS Code.
2. Chạy các lệnh sau:

```bash
npm install
npx shadcn@latest add button card checkbox badge alert dialog tabs input label slider switch select skeleton separator dropdown-menu sonner tooltip
npx prisma migrate dev --name init
npm run dev                     # mở http://localhost:3000
```

Tài liệu thiết kế đầy đủ nằm trong thư mục `docs/`.
